# Windows安装frida

## frida环境

frida需要python3环境，而drozer需要python2.7.1，使用pyenv切换全局python版本

注意：安装pyenv，参照文章：

```
pyenv global 3.13.2      ##切换python全局版本
```

```
pyenv global             ##查看python全局版本
```

![image-20250225113350187](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225113350187.png)

## 命令行安装frida

**注意：此处默认安装是16.6.6，与frida-server连接故障，故换16.4.0**

```
pip install frida==16.4.0
```


# 安装frida-server

## 启动夜神模拟器，在夜神模拟器的安装目录下的"bin"下路径输入“cmd”进入命令行界面

![image-20250225114442569](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225114442569.png)

![image-20250225114505765](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225114505765.png)

## adb连接模拟器

```
adb connect 127.0.0.1:62001
```

![image-20250225114622560](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225114622560.png)

## 查看模拟器信息

```
adb shell getprop ro.product.cpu.abi
```

![image-20250225115750338](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225115750338.png)

## 下载frida-server

```
链接：https://github.com/frida/frida/releases
```

注意：查看夜神模拟器系统信息，此处为32位，若为64位，则下载x86_64的包

![image-20250225120735360](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225120735360.png)

![image-20250225134539027](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225134539027.png)

## 将下载的文件复制到夜神模拟器的安装目录下的“bin”目录下解压，得到文件，将文件重命名为frida-server

![image-20250225122511829](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225122511829.png)

## **推送 frida-server 到模拟器**

```
adb push frida-server /data/local/tmp
```

![image-20250225121534792](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225121534792.png)

## 设置执行权限

```
adb shell "chmod +x /data/local/tmp/frida-server"
```

![image-20250225123013572](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225123013572.png)

## **运行 frida-server**

```
adb shell "/data/local/tmp/frida-server &"
```

## 端口转发

```
adb forward tcp:27042 tcp:27042
adb forward tcp:27043 tcp:27043
```

![image-20250225134732994](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250225134732994.png)

## 测试，连接成功

列出设备上的所有进程

```
frida-ps -U      ##  -U 参数指示 frida-ps 通过 USB 连接到设备
```
