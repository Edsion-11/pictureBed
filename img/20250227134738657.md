# 给Docker配置代理

## 在kali中安装docker

```
apt install docker.io
```

## 启动docker

```
systemctl start docker
```

## 新建目录

```
mkdir -p /etc/systemd/system/docker.service.d
```

## 在“docker.service.d”目录下新建配置文件

```
vim http-proxy.conf
```

## 在该配置文件中输入代理服务器信息

**注意：此处根据自己代理服务器信息填写**

![image-20250224231454215](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250224231454215.png)

## 保存配置文件，重载docker

```
$ sudo systemctl daemon-reload
$ sudo systemctl restart docker
```

## 检查确认环境变量已经正确配置

```
systemctl show --property=Environment docker
```
